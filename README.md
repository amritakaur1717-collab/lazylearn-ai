# lazylearn-ai
AI-powered study assistant that makes learning easier.
## ✨ Features

* 📝 Summarize study notes
* ❓ Generate practice questions
* 🗂️ Create flashcards
* 🧠 Prepare quizzes
* 💡 Explain difficult topics in simple language

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Python
* Flask

## 🚀 Getting Started

1. Download or clone this repository.

2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   python app.py
   ```

4. Open `http://127.0.0.1:5000` in your browser.

**Note:** AI generation requires a working AI service connection.

## 🎯 Goal

LazyLearn AI aims to make studying easier by helping students organize their notes and prepare for revision.

Early-stage project. AI integration and testing are in progress.
